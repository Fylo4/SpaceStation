Draw Machine

Draws cool patterns. There are several rotating arms, and the final arm is holding a pencil. Interval = Delay between simulation steps, in ms. Step multiplier = Simulate multiple steps each step, so you can make it go faster even when interval is 0. Each arm will rotate 'speed' radians per step. The time it takes for it to draw over the same line is related to the least common multiple between the speeds. If you cannot see the machine, un-check and re-check the 'draw machine' button, sometimes it fails to load. Colors can be any CSS color; see https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value
